# Support

We want Flaire to work well for your store. If something doesn't work as described in this documentation, contact us through the support form at [SUPPORT_FORM_URL].

## Before you contact us

- Check the [FAQ](faq.md) and the page in this documentation for the feature you're using.
- Try the problem on an unedited copy of Flaire. In **Online Store > Themes**, add Flaire to your theme library again from the Theme Store, and check whether the problem happens there too. This tells us whether the cause is the theme, an app or a code edit.
- Turn off apps one at a time to see whether one of them causes the problem.

## Support policy

### What's included

- **Theme bugs**: anything in Flaire that doesn't work as described in this documentation, on the latest version of the theme, in a supported browser.
- **Setup questions**: help finding and using the theme's sections, blocks and settings, and setting up features the theme supports, such as filters, pickup, swatches and the size guide.

### What's not included

- **Customizations**: changes to the theme's code, design or layout beyond what the theme settings allow, and problems caused by code edits.
- **App integrations**: setting up, configuring or fixing third-party apps, or problems caused by an app. For help with an app, contact the app's developer.
- **Update help**: moving your code edits or customizations to a new version of the theme.

We may suggest a Shopify Partner if you need work that isn't covered.

### Response time

We reply within two business days, Monday to Friday, excluding public holidays. Most questions are answered in the first reply. If we need to look at your store, we'll ask for collaborator access, which you can approve or decline in your Shopify admin.

### Versions

We fix bugs in the latest version of Flaire. If you're on an older version, we may ask you to update first. See [Release notes](release-notes.md).

## Support contact form

<!-- Specification for the support form on the documentation site. Every field below is required by Shopify Theme Store rules unless marked optional. -->

The support form asks for the details we need to help you quickly.

| Field | Type | Required | Help text shown to the merchant |
|---|---|---|---|
| Name | Text | Yes | Your full name. |
| Email | Email | Yes | We'll reply to this address. |
| Store URL | URL | Yes | Your store's address, for example `your-store.myshopify.com`. |
| Theme name | Select, prefilled with "Flaire" | Yes | The theme you need help with. |
| Theme version | Text | No | Find it in **Online Store > Themes**, under the theme name, for example 1.0.0. |
| Subject | Text | Yes | A short summary, for example "Filters don't appear on the Rings collection." |
| Problem description | Long text | Yes | What you expected, what happened, and the steps to see it. Include the page address where it happens. |
| Screenshots | Image upload (.png, .jpg or .gif, several files allowed) | No, but recommended | Screenshots or a screen recording of the problem. |
| Preview link | URL | No | A preview link to the theme, if it isn't published. In the theme editor, select **Share preview**. |

When the form is sent:

- The merchant sees: "Thank you. Your message has been sent. We'll reply within two business days."
- The form checks that the email address and store URL are valid, and shows a message next to any field that needs fixing.
- An auto-responder email goes to the merchant's email address straight away.
